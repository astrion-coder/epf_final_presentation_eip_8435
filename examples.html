03

Mathematics

Maths in TeX notation [3], rendered by KaTeX [4] and built up step by step.

Mathematics with LaTeX

Inline maths sits in a sentence, like \(e^{i\pi} + 1 = 0\) or \(\hat{\beta} = (X^\top X)^{-1} X^\top y\) for \(X \in \R^{n \times p}\).

Display equation

\[ \int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi} \]

Aligned equations

\[ \begin{aligned} \nabla \cdot \mathbf{E} &= \rho / \varepsilon_0 \\ \nabla \times \mathbf{B} &= \mu_0 \mathbf{J} + \mu_0 \varepsilon_0 \tfrac{\partial \mathbf{E}}{\partial t} \end{aligned} \]

Matrices

\[ A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}, \qquad \det A = -2 \]

Sums and cases

\[ \sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}, \qquad |x| = \begin{cases} x & x \ge 0 \\ -x & x \lt 0 \end{cases} \]

A derivation, one step at a time

\[ ax^2 + bx + c = 0 \]Start from the quadratic
\[ x^2 + \tfrac{b}{a}\,x = -\tfrac{c}{a} \]Divide by \(a\)
\[ \Bigl(x + \frac{b}{2a}\Bigr)^2 = \frac{b^2 - 4ac}{4a^2} \]Complete the square
\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]Take the square root
Each row is a fragment, so the derivation builds up as you press →.

Questions people usually ask

  • How do I change the colours or fonts?

    Edit the tokens in style.css, or start with npm run dev:dark for the dark theme.

  • How do I get a PDF?

    Run npm run pdf. The file lands in the project root as slides.pdf.

  • Can I write slides in Markdown?

    Yes. Put the Markdown in a data-markdown section, like the “Written in Markdown” slide.
